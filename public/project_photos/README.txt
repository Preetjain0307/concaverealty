CONCAVE REALTY - PROJECT PHOTOS DIRECTORY
==============================================================

How to add project photos manually:

1. Open the subfolder of the project you want to update (e.g. '1 - Kalpataru Advay').
2. COVER PHOTO:
   Save your main/cover photo as:
   1.jpg  (or 1.png, 1.webp, 1.jpeg)
   This will automatically appear as the main card photo on the project page!

3. ADDITIONAL GALLERY PHOTOS:
   Save additional photos as:
   2.jpg, 3.jpg, 4.jpg, etc.
   These will appear in the full project details gallery popup!
